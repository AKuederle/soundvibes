# Parakeet backend and live recording

Implement in the main checkout, based on `facd6ae`. Preserve Whisper, Phonon-2,
live vocabulary directory refresh, Linux hotkeys and configured output, including
ydotool. No worktree, active-service install/restart, clipboard changes or Hex edits.

Use pinned transcribe.cpp and verified NVIDIA Parakeet Unified English 0.6B Q8_0
assets. Support Vulkan on Radeon 890M and CPU. During recording begin/feed a
persistent session; finish remaining audio on release. Preserve FIFO output;
cancel abandoned recordings and close sessions on shutdown. Fall back to full-clip
offline inference when streaming is disabled, unavailable or fails. Keep inference
local. Buffered streaming has encoder overlap and lookahead, not immediate words.

Agreed test seams: CLI/TOML config, TranscriptionWorker ordering/fallback/cancel,
and asset-gated real acceptance tests. Explicit asset configuration must exercise
real recognition and fail on bad assets; normal tests skip unavailable assets.
Map acceptance tests in docs/acceptance-tests.md.

Review units:
1. Offline backend, process isolation, config, asset preparation, real acceptance.
   Gate: config and existing unit tests, companion build, real model test; commit.
2. Live worker/recording integration, fallback/cancellation, vocabulary and tests.
   Gate: focused streaming and daemon tests plus real streaming test; commit.
3. Full format/lint/test/release build, per-commit RoboRev closure, curated full-range
   review and corrections, pull/rebase and push main. Record hardware coverage gaps.

The companion process prevents incompatible bundled ggml versions from linking
into one address space. Keep both executables beside each other when deploying.
